Este es un archivo HTML de prueba creado para mostrar que puedes crear nuevos archivos dentro del proyecto y darles un estilo similar al resto de la wiki.

Inicio

La idea de esta prueba es validar que el archivo se crea correctamente, se ve bien y mantiene una estructura ordenada tipo wiki.

Objetivo

El objetivo es tener una página base con un estilo visual oscuro, útil para artículos, fichas o perfiles dentro de una red de contenido digital.

Resultado

Como puedes ver, el archivo quedó con una apariencia limpia, visualmente consistente y lista para personalizar con más información si lo necesitas.
