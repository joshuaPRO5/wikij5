## ¿Qué es WikiJ5?

WikiJ5 es una wiki del creador de contenido **JoshuaPRO5**, fundada y publicada oficialmente el **9 de agosto de 2026**. En esta wiki puedes encontrar información sobre Joshua que no está disponible en ningún otro lugar de Internet, recopilada y organizada en formato de artículos.

El sitio está construido con **HTML, CSS y JavaScript** puro (sin frameworks ni backend), y se publica como sitio estático a través de **GitHub Pages**.

## Ejecutar en local

Como es un sitio estático, no requiere instalación ni dependencias:

```bash
# Clonar el repositorio
git clone https://github.com/joshuaPRO5/wikij5.git

# Entrar al directorio
cd wikij5

# Abrir index.html en tu navegador
# Doble clic sobre el archivo, o:
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

## Contribuir

Las contribuciones son bienvenidas. Al no contar con un servidor para gestionar envíos directos, las colaboraciones se realizan mediante **solicitudes (pull requests)**:

1. Haz un *fork* del repositorio.
2. Crea una rama para tu cambio: `git checkout -b mejora/mi-cambio`.
3. Realiza tus cambios y haz *commit*.
4. Abre un *Pull Request* describiendo los cambios.
